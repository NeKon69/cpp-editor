# CPP EDITOR - THE ONLY EDITOR YOU NEED

Tired of IDEs that are fast, stable, and support more than one programming language? Do you believe that tools should be as difficult and unforgiving as the language they are for? THEN LOOK NO FURTHER.

# THIS EDITOR'S FEATURES:
-   **Code completions, which show up even when you don't want them to:** Imagine you are writing `int`, how about `__international_cpp_extension_from_msvc`? Looks exactly what you wanted to type to me! Powered by a real `clangd` language server, so when it's wrong, it's wrong with *authority*.
-   **OUR INAVATIONAL FEATURE: LINE NUMBERS!!!!!:** You know the drill, editors usually support numbers, we support line numbers, always 2 steps ahead. 
-   **Trippy shader background that i stole from terraria mod!:** Your code fails with segfault and you don't know where your bug is? No problem! This isn't just any background. It's a symphony of visual noise featuring **Chromatic Aberration**, **God Rays**, and **Film Grain**. Perfect for inducing motion sickness while you search for that null pointer.
-   **Ability to open ONLY C++ files! Cause who needs other languages?:** You said you support any language? I think that every language besides C++ is an obstacle in your path to success. the more lines you write in c++ the closer you are to being homeless! Ideal!
-   **File tree, where you can rename and delete any file, but you can create only C++ files, because that's all we need!:** Yea, python is at the bottom of the bottle, which is where it's supposed to be! The context menu will literally tell you "only the best language is allowed". God bless C++.
-   **A Built-in Terminal that is really laggy, but who cares?:** If you are on linux, then I am 10000 times sorry for you, cause if you run the `yes` command, or something that prints out a lot of text, my editor will not recover. This is a feature to encourage concise command line usage. Sucks to be you!
-   **Diagnostics Panel to Constantly Remind You of Your Failures:** A dedicated panel lists every single error and warning `clangd` can find. It's like having a backseat driver for your code, except the car is on fire and you're heading for a cliff.
-   **Ability to create basically any highlighting colors! (but everything else is dark, cause no flashbangs for you):** Ah yes! Freedom! (limited). Make your code look like a unicorn threw up on it. We don't care. As long as the background stays dark.
-   **TWO!!!! Databases that are completely unnecessary but required by the project, so I put every setting I had in them, LOL!:** One of them is saved in your project's directory, and another one is in a location you probably won't even look in! 

# And Finally, My Magnum Opus

-   **Genius syntax highlighting that was developed by me for this project because the library I used didn't support semantic tokens! PERFECT!** It's not just syntax highlighting, it's a Rube Goldberg machine! It first runs a C++ preprocessor on your file, then feeds the expanded macros and headers into `tree-sitter` to build a full syntax tree, and *only then* does it decide what color your `int` should be. You don't understand this masterpiece. Breathtakingly inefficient, but it's ART. And it's super slow, but at least it's mine!

# HOW TO USE THAT APP

-   Clone the repo. You know how to do that.
-   Install the dependencies with `pip install -r requirements.txt`.
-   Run `main.py`. On Wayland you may need `QT_QPA_PLATFORM=xcb python main.py`.
-   You can luanch it with `python main.py` I'm sure you want to edit my python code! Or with specifying a directory `python main.py /path/to/your/project`.
-   **CRITICAL STEP:** Make sure you have a `compile_commands.json` file in your project root. If you don't, my editor will try to generate a default one that is guaranteed to be wrong. And because I am evil i will not tell you what structure it should contain, but any C++ developer know it's structure, so you should be qualified and prove that you are worthy to use this editor!
-   Then just start coding in the best language ever, which is as we know is C++.
-   There are some shortcuts but you can learn all of them by looking at the top bar of the app, and seeing stuff such as "File", "View", etc.. Click on them and you'll see what is available!
-   Here are some of them: Use `Ctrl+Space` for forced autocomplete request to lsp server, Use `Ctrl+~` to show errors in the current line! (most important feature)
